# Security policy

## Non-medical use

This is community-maintained software for technical interoperability. It is
not medical advice, a certified medical device, or suitable for diagnosis or
treatment decisions. Security reporting and remediation do not change that
limitation.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting feature for this repository when
it is available. Repository maintainers should enable that feature before the
public release. Do not include exploit details in a public issue.

Never include health measurements, device identifiers, serial numbers, BLE
captures, database files, raw protocol bytes, or exported records in a report.
Provide a minimal synthetic reproduction instead.

## Scope

Security reports may cover this repository's source code, packaged artifacts,
and supported command-line workflows. The project does not operate a hosted
service or collect telemetry.

This project cannot promise a response-time or remediation-time commitment.
